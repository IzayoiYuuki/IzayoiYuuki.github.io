About this map.

A personal photographic journal

The map connects places with visits, photographs and bird information. It is not a guide to current bird sightings, access conditions or navigation. Entries marked “Example” are interface demonstrations, not records of personal visits. Their shared sample photograph comes from the existing homepage and has not been assigned to any of those locations.

Location privacy

A map pin can represent a reserve centre or another suitable public location. The “approximate” label does not automatically blur coordinates: the maintainer must choose a safe public point. Hidden locations have no coordinates in either the map index or the public location file. Location names, dates, notes and photograph content still require manual review.

The importer produces new web-sized copies without EXIF or XMP metadata. It does not alter the original photographs or retroactively remove files from an existing Git history. Existing homepage images are outside this import workflow.

The local overview

The local overview uses a bundled GeoJSON coastline extract and city labels. It supports mouse-wheel zoom and works without online map services. It is a simplified regional context map, including Great Britain, Northern Ireland and the northern island groups; it is not suitable for navigation.

Coastline and lake data: GSHHG, via basemap-data 2.0.0, derived from GSHHG 2.3.6. The regional extract is licensed under LGPL-3.0-or-later. It has been clipped, simplified and rounded for this overview. The editable coordinate source is uk-context.geojson; the repository also contains tools/rebuild_map_outline.py. Copies of the LGPL and GPL are included.

Local city and town labels are selected from Natural Earth populated places, which are public domain. Labels are cartographic context, separate from the personal birding records.

The detailed street map

The default detailed map uses a locally bundled copy of Leaflet 1.9.4 (BSD-2-Clause license) and requests OpenStreetMap tiles for the current view. Roads and place names appear as you zoom with the mouse wheel, controls or touch gestures. Overview switches to the local map, which is also available when online tiles cannot be loaded. The tile service receives ordinary connection information such as your IP address. This page does not request your device location, provide analytics or set application tracking cookies.

Map data © OpenStreetMap contributors, ODbL. Tiles are subject to the OSM tile usage policy. The optional local-editor location search uses Nominatim under its usage policy, with manual confirmation, throttling and local caching. There is no visitor-side geocoding.

Photographs and accessibility

Photographs remain the property of their owner. Information is also available through the static photo catalogue without JavaScript or the interactive map. Map locations can be selected by tabbing to a marker and pressing Enter. All published places, including those without map pins, are available in the static photo catalogue. In the photo viewer, use Escape to close and the left/right arrow keys to move between photographs.
